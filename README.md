# Predicción de goles del equipo local en la Premier League con Machine Learning

## Autores
Mateo Amaya Moreno 2250921, Carlos Daniel Martínez Ramírez 2250917, Alejandro Ramírez Mejía 2250930

## Objetivo
Predecir la cantidad de goles que anota el equipo local en un partido de la Premier League a partir de estadísticas previas al encuentro.

## Dataset
Estadísticas de equipos y resultados de partidos de la Premier League, en dos archivos CSV:

- [Estadísticas (`stats_df`)](https://drive.google.com/uc?id=1LxkcMGkaHML90Byj7629y-byZz5FGoU-)
- [Resultados (`results_df`)](https://drive.google.com/uc?id=1E36QY6b0PSxwjzQpglaHcHC0Jbl2dqs4)

## Modelos
Gaussian Naive Bayes, Decision Tree, SVM, Random Forest, Regresión Lineal, Red Neuronal (MLP), GridSearchCV, KFold, RMSE, F1, Gradient Boosting.
